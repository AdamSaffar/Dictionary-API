# Dictionary Side Panel Extension
A simple Chrome extension tool that lets you look up word definitions without leaving your current tab. It opens in a side panel so you can keep reading your article while you learn new words.

## Feature
* **Right-Click to Lookup:** Highlight any word on any webpage, right click your selected text, then find and click on the context menu item to define it!
*  **Navigate Inside Side Panel:** Click on synonyms to start a new search!
*  **Back Button:** A LIFO (Last In First Out) history stack allows you to navigate back through your search history without extra API calls.
*  **Audio Support:** Listen to correct word pronunciations with the built-in audio player.

## Installation
1. **Clone the repo:**
`git clone https://github.com/AdamSaffar/Dictionary-API.git`
2. **Open Chrome Extensions:**
Search for `chrome://extensions/` in your browser
3. **Developer Mode:**
Be sure to enable developer mode(located top right of page)
4. **Load Unpacked:**
Lastly, click the load unpacked button(top left of page) and select your project folder.
